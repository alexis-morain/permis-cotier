# Captures des fiches-mémo

Chromium headless (`chrome-headless-shell`), `dist/` (site, 1280 de large) et
`dist-app/` (app, 390 de large, `html[data-app]` venu du build), servis depuis
le disque. Clair et sombre par `prefers-color-scheme`.

- `site-feux-marques-*` : `/cours/feux-marques/memo` sur le site.
- `app-feux-marques-*`, `app-balisage-*`, `app-signaux-*` : les trois fiches
  de la première série, dans l'app.

Les premiers blocs de « feux et marques » n'ont pas de schéma : leurs leçons
n'en montrent pas. Le balisage et les signaux en portent plus.
