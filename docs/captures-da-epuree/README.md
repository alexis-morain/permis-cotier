# Captures avant/après de la DA épurée

`avant-*` : `main` à `eef7d82`. `apres-*` : la branche `app-da-epuree`. Même état de
progression pour toutes (trois examens, des questions dues, une date d'examen),
iPhone 390 × 844, clair et sombre, build `npm run build:app` servi en local.

Écrans : accueil, question, question cochée, correction juste, correction
fausse, résultat d'examen, fiche, cours, leçon. Réduites à 600 px de haut.

Ce sont des rendus de navigateur : ils ne remplacent pas un essai sur
simulateur ou sur iPhone (Dynamic Type, zones sûres, appui).
